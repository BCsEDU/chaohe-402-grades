# 學生成績管理系統（402 班）

免後端、免安裝、資料完全存於使用者本機瀏覽器 `localStorage` 的班級成績管理網頁。

## 功能特色
- **座號與測試座號隔離**：預設 1～29 號，29 號為測試座號（預設不計入班級平均、及格率與參考排名）。
- **六大科目與三大類別**：涵蓋國語、數學、綜合、體育、彈性、校本；支援多次小考自由新增、期中考、期末考直接登錄（無加權、無等第，單純算術平均）。
- **防誤觸直欄鎖定**：每一欄考試標頭皆可單獨切換 `🔓` / `🔒 已鎖定`，鎖定後無法編輯、調分、刪除或被 CSV 覆蓋。
- **學生協助登打模式**：以教師解除密碼（預設 `4020`）保護，開啟後自動隱藏姓名與其他分頁，僅開放「選擇科目、新增考試項目、輸入未鎖定欄位成績」。
- **CSV 快速上傳與匯出**：支援 UTF-8（含 BOM）與台灣 Excel Big5 自動辨識，原生支援 Apple Numbers 雙列合併標題、同科重複欄名區分、`X` 免考辨識、匯入預覽與一鍵復原，並可匯出單科明細、全科總表與完整備份 CSV。
