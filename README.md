# 學生成績管理系統（402 班）

整合 Supabase 雲端跨裝置即時同步與本機離線備援的班級成績管理網頁。

## 功能特色
- **雙重身分登入（平板＋教師電腦同步）**：
  - **教師雲端工作台**：沿用既有 Supabase 專案 `ppdgubracsneozahujxl` 的 `teacher_config` 密碼驗證，完整管理所有科目、鎖定直欄、CSV 匯入／匯出與設定（支援每 5 秒自動背景同步）。
  - **學校平板・學生協助登打（`?mode=helper`）**：以教師自訂通行碼登入（預設 `4020`，可於後台隨時關閉或換碼），由後端 Edge Function `grade-sync` 強制限制僅開放「選擇科目、新增考試項目、輸入未鎖定欄位成績」，看不到姓名，也無法改鎖定欄或設定。
- **座號與測試座號隔離**：預設 1～29 號，29 號為測試座號（預設不計入班級平均、及格率與參考排名）。
- **六大科目與三大類別**：涵蓋國語、數學、綜合、體育、彈性、校本；支援多次小考自由新增、期中考、期末考直接登錄（無加權、無等第，單純算術平均）。
- **防誤觸直欄鎖定**：每一欄考試標頭皆可單獨切換 `🔓` / `🔒 已鎖定`，鎖定後無法編輯、調分、刪除或被 CSV 覆蓋。
- **CSV 快速上傳與匯出**：支援 UTF-8（含 BOM）與台灣 Excel Big5 自動辨識，原生支援 Apple Numbers 雙列合併標題、同科重複欄名區分、`X` 免考辨識、匯入預覽與一鍵復原，並可匯出單科明細、全科總表與完整備份 CSV。
